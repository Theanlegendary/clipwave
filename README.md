# OmniDrop - Social Video Downloader 🚀

A modern, fast web application for downloading videos and audio from YouTube, TikTok, Instagram, Twitter/X, Facebook, and hundreds of other platforms.

## ✨ Features

- **Multi-Platform Support**: YouTube, TikTok, Instagram, Twitter/X, Facebook, Reddit, Pinterest, and 500+ more (powered by `yt-dlp`).
- **One-Click Paste**: Automatically reads and inspects links directly from your clipboard.
- **Multiple Qualities**:
  - ⚡ Best Quality MP4 (up to 1080p/4K with audio merged)
  - 📺 720p HD MP4
  - 📱 480p SD MP4 (Data Saver)
  - 🎵 Audio Only (MP3 192kbps)
- **Automatic Storage Cleanup**: Temporary download files are automatically purged so your disk never fills up.
- **Sleek Modern UI**: Responsive dark design with Tailwind CSS and Lucide icons.

---

## ⚡ How to Launch

### Option 1: One-Click Launch (Windows)
Double-click **`start.bat`**.  
It will automatically activate the environment and open `http://127.0.0.1:5000` in your web browser.

### Option 2: Command Line
1. Open PowerShell or Terminal in this folder:
   ```powershell
   .\venv\Scripts\activate
   python app.py
   ```
2. Open your browser to:
   ```
   http://127.0.0.1:5000
   ```
